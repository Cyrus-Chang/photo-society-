# Acceptance checklist

## 尺寸和布局

- [ ] 375 / 390 / 768 / 1440 均无横向溢出。
- [ ] 首屏主任务、标题和主要操作在窄屏仍可见。
- [ ] 图片有稳定的宽高约束，加载前后不跳动。
- [ ] 长标题、长标签、空列表和接口慢响应不会破坏布局。

## 状态和可访问性

- [ ] loading 有骨架或明确忙碌状态。
- [ ] empty 说明原因并给出下一步。
- [ ] error 说明来源和可恢复动作，不白屏。
- [ ] focus-visible 清晰；键盘能走完主要任务。
- [ ] 正文对比度 ≥ 4.5:1，正文建议 ≥ 15px，行高 1.5–1.7。
- [ ] `prefers-reduced-motion` 下不循环播放大位移或粒子。

## 视觉和实现

- [ ] 只有 1 个 signature effect，support 不超过 4 个。
- [ ] 颜色来自 token；没有无理由新增裸十六进制值。
- [ ] 所有动画通常 ≤ 400ms，除非开场叙事有明确理由。
- [ ] 图片、图标、字体加载失败时仍可读可操作。
- [ ] 真接口、mock、降级和统计口径在 UI 中诚实标注。

## 证据格式

```text
尺寸：375 / 390 / 768 / 1440
截图：路径或附件
命令：命令 + 原始输出
规则：UX/栈规则 ID → 实现位置 → 结果
未做：没有截图或服务不可用的项
冲突：工作区既有改动、未触碰的文件
```
