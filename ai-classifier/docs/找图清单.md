# 找图清单（风格锚图 · 13 类 × 4 张）

给找图的人：**一共 52 张，宁缺毋滥。** 这批图只做"参考标尺"（每类一个原型中心），不是训练集，
所以要的是**典型**，不是好看。

---

## 一、通用硬要求（不符合的直接不要）

| 项 | 要求 | 为什么 |
|---|---|---|
| 水印/logo/贴纸 | **绝对不能有** | 模型会学"这里有个水印"，而不是学调色 |
| 分辨率 | 长边 ≥ 1000px，原图 | 缩略图/截图会让色彩统计失真 |
| 来源 | 自有作品 / 授权图库（Pexels、Unsplash、CC0）/ 朋友授权的片子 | 这批图会进训练流程，来源要说得清 |
| AI 生成图 | 不要 | 一眼假的那种，光影和颗粒分布不对 |
| 拼图/九宫格 | 不要 | 一张图只能是一个风格 |
| 内容 | 同一类尽量同一题材（人像就都人像，静物就都静物） | 否则模型学到的是"题材差异"而不是"风格差异" |
| 重复 | 一张图只投一类；同一组 4 张别来自同一个摄影师 | 需要能代表这一类，不是代表某个人 |

## 二、13 类逐条（找什么 / 别拿什么充数）

### 1. 日系 `JAPANESE`
- **长什么样**：低饱和、亮、柔光、轻微高光溢出、偏青绿、有空气感/通透感
- **关键词**：日系 写真 / 日系 少女 / 空气感 / japanese film portrait / soft airy photography
- **别拿**：锐利留白的那种（那是 ins）、有明显颗粒的（那是胶片）

### 2. 韩系 `KOREAN`
- **长什么样**：奶油感，皮肤通透白皙偏粉，浅色调，低对比，画面干净，锐度偏高；棚拍或咖啡馆
- **关键词**：韩系 写真 / 韩系 棚拍 / 奶油肌 / korean studio portrait / creamy skin tone
- **别拿**：偏青绿有灰雾的（那是日系）、强调大面积留白的（那是 ins）

### 3. ins 风 `INS`
- **长什么样**：高亮、低对比、黑位不死黑、留白多、构图规整有几何秩序、更锐更"干净"
- **关键词**：ins风 / 极简 留白 / minimal instagram / negative space photography
- **别拿**：柔光空气感的（那是日系）

### 4. 清新 `FRESH`
- **长什么样**：高明度、低饱和、通透、浅色、阳光感，比日系更白更亮
- **关键词**：清新 写真 / 日系 清新 / 高调 / fresh bright airy / high key pastel
- **别拿**：偏青绿带灰雾的（那是日系）— 注意清新和日系**可以同时成立**，不必强行二选一

### 5. 胶片 `FILM`
- **长什么样**：颗粒明显、黑位抬升（暗部发灰）、青影暖高光、对比柔和、高光轻微溢出
- **关键词**：胶片感 / 胶片 扫描 / film emulation / portra 400 / grain photography
- **别拿**：只有褪色黄褐没有颗粒的（那是复古）

### 6. 复古 `VINTAGE`
- **长什么样**：褪色感，整体低饱和，黄褐偏移，对比柔和，年代感
- **关键词**：复古 / 褪色 / 老照片 / faded vintage photography / retro color cast
- **别拿**：有颗粒的（那是胶片）— 两者可共存，但请按"主特征"归类投

### 7. 电影感 `CINEMATIC`
- **长什么样**：青橙调色（暗部偏青、高光偏橙）、S 形对比、两端不裁切、常有宽画幅
- **关键词**：电影感 / 青橙 / teal and orange / cinematic color grading
- **别拿**：青+品红霓虹的（那是赛博）、没有双色对冲的（那是欧美）

### 8. 暗调 `DARK_MOOD`
- **长什么样**：大面积暗部、单一光源、明度低、阴影占比高，**可以是暖的**
- **关键词**：暗调 / low key / moody portrait / single light source
- **别拿**：暗但高饱和霓虹的（那是赛博）、暗但整体偏蓝的（那是蓝调）

### 9. 黑白 `MONO`
- **长什么样**：完全去色，只有灰阶
- **关键词**：黑白 / 单色 / black and white / monochrome
- **别拿**：任何带一点色调的图（灰度图可以自己转，转完算这一类）

### 10. 蓝调 `BLUE_TONE`
- **长什么样**：整体偏蓝/青蓝，白平衡偏冷，暗部明显偏冷；**可以亮也可以暗**
- **关键词**：蓝调 / 冷调 / blue hour / cold tone photography
- **别拿**：只是偏暗的（那是暗调）、偏青绿的（那是日系）

### 11. 港风 `HK_RETRO`
- **长什么样**：绿青在中间调、暖肤色、硬光、年代颗粒、港片式的构图和姿态
- **关键词**：港风 / 复古港风 / 王家卫 / hong kong retro / neon night portrait
- **别拿**：整体色彩均匀偏移的（那是胶片）

### 12. 赛博 `CYBER`
- **长什么样**：霓虹高饱和、青+品红对冲、硬光、暗部保留高饱和光斑、夜城/室内霓虹
- **关键词**：赛博朋克 / 霓虹 / cyberpunk / neon lights portrait
- **别拿**：只有一片蓝的（那是蓝调）、只是暗的（那是暗调）

### 13. 欧美 `WESTERN`
- **长什么样**：杂志/时尚 editorial 感，高反差、硬光、强轮廓阴影、妆造强烈、姿态张扬
- **关键词**：欧美 时尚 / editorial / vogue portrait / hard light fashion
- **别拿**：大面积暗部为主的（那是暗调）、有统一青橙调色的（那是电影感）
- ⚠️ 这一类定义最宽，最容易和别的混。**找不典型就跳过，宁可这一类只有 3 张。**

## 四、找图的人自检三问

1. 这张图**第一眼**就能让人说出这是 X 风格吗？犹豫的不要。
2. 图上有没有任何水印、logo、字幕、边框？有就不要。
3. 同一类的 4 张，是不是同一个摄影师拍的？是的话换两张。
