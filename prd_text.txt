约拍市场已验证痛点：修图拖延、临时放鸽子、现场加价、拍完失联。抖音、小红书解决了"看到好作品"，但"看到"和"拍到"之间是断的——评论区求联系方式、私信石沉大海。AI 写真产品（如妙鸭）生成的是假照片，接不到真人。本产品接的就是"看到 → 拍到"这一段。 抖音 / 小红书 = 流量分发 作品被不被看见，算法说了算，摄影师得卷内容、攒粉丝。 筛的是"谁的内容好看"。 本平台 = 需求筛选 用户说清楚要什么，AI 从全部作品里把对的那张筛出来， 没有粉丝的摄影师也能被选上 。 筛的是"你要的这张是谁拍的、他能不能准时到场"。 1.3 目标用户 想被拍的人 （coser、想要约拍的普通用户）· 摄影师 （接单赚外快或主业）· 摄影爱好者 （找搭子、发作品）。起步圈子：cos 圈。 1.4 术语表 本文档统一使用以下称呼，避免圈内黑话造成误读： 术语 含义 约拍 客户与摄影师约定时间、地点进行拍摄的行为，本平台的核心交易。 需求帖 想被拍的人发的帖：时间、地点、拍什么，等摄影师来接。 档期帖 摄影师发的帖：某天在某地可约，客户看到直接下单。 搭子帖 找同去某地拍摄同伴的帖，分「接外快」与「纯搭子」两种（FR-3.1）。 成单 双方确认约拍、订单成立的状态。 返图 拍摄后摄影师向客户交付成片。 出片 产出 / 交付成片，出片回流即拍完的片子发回圈子（FR-4.3）。 场照 漫展等活动现场拍的日常向照片（圈内通用语，用于冷启动灌入作品库）。 互勉 不收钱的互相拍摄——你拍我、我拍你。 外快 顺路带拍收取的象征性费用，区别于正常约拍市场价。 2 产品结构 模块 A 约拍（需求端） 想被拍的人用。所有"我要拍"的动作都在这—— 筛地方、约摄影师、发需求帖、看档期帖急约 。主入口是跟 AI 说场景、AI 筛作品。 模块 B 接单（供给端） 摄影师用。所有"要我拍"的动作都在这—— 确定地址时间接单、发档期帖揽客、发搭子帖 带外快或找搭子。 模块 C 搭子广场 摄影爱好者聚集地。 发作品、约着去某地、要去某地可以带人一起拍 ，价格自己商量。 两边的帖子在拍摄集市里流动，共三种： 需求帖 · 想被拍的人发 档期帖 · 摄影师发：那天在哪可约 搭子帖 · 摄影师 / 爱好者发：顺路带拍 / 找搭子 3 功能需求 3.1 约拍模块（需求端） FR-1.1 AI 筛作品主入口 P0 用户用说人话的方式描述场景并 定下自己要去的地方 （某个景点或限定地区，定的是去处，不是 AI 替用户挑景点），AI 按地点＋场景从作品库筛出能去那边拍的摄影师作品。 你说场景，定地点 ："我周六出古风角色，要去西安小寨，想要夜景灯笼那种感觉的。" AI 筛作品 ：按地点＋场景，挑出能去那边拍的作品——不同摄影师，直接看图，不给名单。 你选一张最喜欢的 ：选完直接亮出——这张是 TA 拍的。 AI 顺带补备选 ：顺着风格再补 1-2 位同风格摄影师。 你挑人 ：翻主页、看档期，确定就约——进 FR-5 约拍流程。 冷启动规则 ：作品库起步靠 cos 圈存量场照灌入＋拍完默认回流（FR-5.3）；作品少时 AI 降级为"按地点＋时间筛人"，从"选一张"变"挑一位"。 FR-1.2 刷作品约 TA P0 作品页和摄影师主页提供「约 TA」按钮，点击填写时间、地点，直接进入约拍流程。 FR-1.3 发需求帖 P1 挂出"时间、地点、拍什么"， 可填期望价（可不填） ，等摄影师来接。想拼的可在帖子里喊人，凑好后 推一人发帖代表整单 、备注可拼。（多人拼单功能待定，见 §8） FR-1.4 看档期帖急约 P1 "今天在哪能拍"——当天的事走档期帖，看到合适的直接约。 例："今天小寨有漫展没摄影师" 3.2 摄影师模块 FR-2.1 接单 P0 需求帖、约 TA 发来的单，确定地址、时间、 最终价 ，看了接了就成（定价规则见 FR-5.1）。 FR-2.2 发档期帖揽客 P1 "那天在哪、还有几个空位"，客户看到直接下单。把漫展现场蹲点拉客搬到线上。 例："周六长安十二时辰，可约" FR-2.3 发搭子帖 P1 找搭子、顺路带外快——见 FR-3。 3.3 搭子模块 FR-3.1 搭子三件事 P1 发作品 （同好互相看见）· 约着去某地 （发搭子帖，同好报名）· 要去某地带人一起 （本来就要去，顺路带拍）。 标签规则 ：带拍帖发帖时自选标签，同一入口、两种关系—— 接外快 （顺路接一两单，收象征性费用）与 纯搭子 （一起采风、互相掌机，AA 或不谈钱）。谈钱的和谈感情的分开。 3.4 圈子与集市 FR-4.1 同好圈子（主板块） P0 发场照、聊镜头、聊出片——内容和人留下来。 作品流按"新＋近地"排 （时间＋所在地区），配地点、风格标签墙，点标签筛；有关注、有收藏， 没有粉丝权重的推荐位 。 FR-4.2 拍摄集市（副板块） P1 三种帖（需求帖 / 档期帖 / 搭子帖）集中流动，纯办事效率区——没有关注、没有动态流。 圈子养人，集市办事 。 FR-4.3 出片回流 P1 拍完的片子发回圈子，变成下一个人刷到的作品——刷到 → 约 → 拍 → 再刷到。 首发规则 ：默认摄影师发圈子并 @ 客户，客户想发自己修的版本就转发到自己主页——只有一个首发源，同一组图不打架。 肖像授权 ：含客户可识别人脸的作品，摄影师发布前须勾选"已获客户同意"；客户可要求不 @、不打标签（匿名化）或下架。客户自己发布的版本不受此限。 3.5 交易流程 FR-5.1 约拍流程 P0 发帖 → 接单 → 确认 → 拍摄 → 互评收尾 客户发需求帖 / 点约 TA，或摄影师发档期帖，哪边先开口都行。确认时 价格写死在单里 ；拍完互评一次并标记"已结清"留凭证。 定价规则 ：发单方可填期望价（可不填，见 FR-1.3）；摄影师接单时填写最终价，客户确认后价格写死进单，此后改动须双方在单内重新确认。线上谈价，线下付款。 订单状态 ：待确认 → 已确认 → 已完成 / 已取消。开拍前任一方可取消；取消与爽约的处理方式见 §5.3（待拍板）。 互评规则 ：标记"已完成"后 7 天内可互评；双方都提交或窗口到期后互相可见；"已结清"由客户标记，摄影师可见。 FR-5.2 搭子流程 P1 发帖 → 报名 → 成行 → 收尾 发起人发搭子帖（时间、地点、拍什么、接外快还是纯搭子、还差几人）；想去的点「一起」， 发起人翻报名者主页再决定拉谁，不是先到先得 ；人满或到时间帖子锁定，平台内开临时群聊对细节；出了片子发回圈子。 帖子状态 ：报名中 → 已锁定（人满或到时间）→ 已完成。 3.6 沟通与通知 FR-6.1 平台内沟通 P1 会话按帖和单自动生成：约拍单生成双方会话，搭子帖成行后建临时群聊，收尾后归档只读——交易相关沟通留在平台内，自然留痕（衔接 §5.2）。（群聊详细功能范围待定，见 §8） FR-6.2 站内通知 P1 覆盖关键节点：被接单 / 客户确认 / 新报名 / 成单 / 成行 / 拍摄当日提醒 / 互评与结清提醒。通知不接短信和推送，站内红点即可。 4 AI 能力需求 评分吃 AI，更吃"AI 真的接在交易主线上"——所以 AI 能力全部挂在主流程上排优先级。 编号 能力 优先级 需求描述 AI-1 作品智能入库 P0 摄影师传图，AI 自动打标签（地点 / 风格 / 服装类型 / 光线）。没有它，AI 筛作品就是空话。 AI-2 AI 筛作品主入口 P0 即 FR-1.1 五步：定地点 → 筛作品 → 选图亮作者 → 挑人。核心卖点，必须能现场演示。 AI-3 AI 风格预演 P1 上传自己的照片，按摄影师作品风格生成"你拍出来大概什么样"。做简化版：参考图＋风格化生成，照片只用于本人预览。 AI-4 AI 拍摄攻略 P1 定完地址，AI 顺带给机位、光线时段、人流高峰、场地收费提示。工作量小、贴主入口。 AI-5 AI 搭子撮合 P1 按地点＋时间＋风格自动配对——"你俩周六都要去翠华山，拉个群？"让搭子模块不是摆设。 AI-6 AI 档期助手 P2 摄影师一句"这周末都在小寨"，AI 生成档期帖＋接单自动回复——摄影师侧的 AI 着落。 AI-7 互评画像摘要 P2 AI 把标签＋评语浓缩成一句人话："修图快、不鸽，适合第一次约拍的人。" 后续路线图（本期不做，写进参赛材料） ：活动雷达（漫展日历＋AI 订阅推送）、行情价参考、AI 需求单翻译、成单共享相册、AI 修图分级。 5 安全与信任 5.1 双向痛点 想被拍的人怕 ：到地了随处找一个陌生人；付了钱答应修图的但人跑了。 摄影师怕 ：约好了被放鸽子；拍完拿不到钱；需求现场无限加。 5.2 轻安全三件套（对两边同时生效） 平台内沟通 ：交易相关的沟通留在平台内，自然留痕。 拍摄行程共享 ：分两层——① 基础互见 ：成单后，拍摄时间、地点、对方身份互见，成单即生效；② 实时位置共享 ：仅拍摄时段内、仅对当次成单对象开放，主动开关， 默认关 。不存在"朋友可见"这类常驻位置暴露。 拍后双向互评 ：拍完互评一次，不打分——点标签，供后面的人挑人时参考。评语可写可不写。 给摄影师点的标签 ：准时到场 / 出片快 / 好沟通 / 引导有一手 / 修图靠谱 / 现场不磨叽 / 会找机位 / 物有所值 给客户点的标签 ：准时到场 / 沟通顺畅 / 不临时加需求 / 尊重成片风格 5.3 爽约处理 待定 三件套是事后的，鸽子是事前飞的——候选方案待拍板。 注意 ：方案 c（意向金）要求平台代收资金，与 §9"平台不经手钱"的边界冲突——选 c 则必须同步修改 §9，选 a / b 则边界不动（见 §8）。 方案 做法 评价 a 不处理 靠圈子眼熟兜底——最彻底，但痛点悬着。 b 爽约记录互见 取消 / 爽约只在双方主页留一条记录，不打分、不排行——最轻，但离"不建信用体系"的界线最近。 c 可选意向金 拍前付一点，拍完抵扣，放鸽子归对方——最有效，但最接近重契约。 6 摄影师等级体系 P2 · 待定 整章降为待定（2026-11-02 决策） ：L1-L5
